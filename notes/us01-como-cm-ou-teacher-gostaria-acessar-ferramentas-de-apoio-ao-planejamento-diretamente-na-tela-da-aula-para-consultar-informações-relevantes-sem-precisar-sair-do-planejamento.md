---
title: "[US01] Como CM ou Teacher, gostaria acessar ferramentas de apoio ao planejamento diretamente na tela da aula, para consultar informações relevantes sem precisar sair do planejamento."
---


| AC01 – | O sistema deve disponibilizar o menu de Planning Tools na tela de planejamento da aula.                                                 |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| AC02 – | O sistema deve identificar cada ferramenta disponível por meio de um ícone e uma label.                                                 |
| AC03 – | O sistema deve abrir o painel correspondente à ferramenta selecionada sem redirecionar o usuário para outra página.                     |
| AC04 – | O sistema deve manter apenas uma ferramenta aberta por vez.                                                                             |
| AC05 – | O sistema deve permitir que o usuário feche o painel da ferramenta selecionada.                                                         |
| AC06 – | O sistema deve permitir que o usuário feche o painel da ferramenta selecionada ao selecionar novamente a ferramenta que estiver aberta. |
| AC07 – | O sistema deve manter a ferramenta selecionada visualmente destacada enquanto seu painel estiver aberto.                                |
| AC08 – | O sistema deve disponibilizar rolagem interna no painel quando o conteúdo ultrapassar a área disponível para visualização.              |
