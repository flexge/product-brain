---
title: "[US02] Como teacher, quero acessar o histórico de notas do aluno por meio de uma Planning Tool na tela de planejamento da aula, para consultá-lo de forma rápida e prática sem sair do contexto do planejamento."
---

| AC01 – | O sistema deve disponibilizar uma ferramenta de acesso ao histórico de notas do aluno no menu de Planning Tools da tela de planejamento da aula. |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| AC02 – | A ferramenta de notas deve ser identificada por um ícone e uma label próprios. |
| AC03 – | Ao selecionar a ferramenta de notas, o sistema deve abrir o histórico de notas no painel correspondente da tela de planejamento da aula. |
| AC04 – | O sistema não deve redirecionar o teacher para outra página ao abrir o histórico de notas. |
| AC05 – | O sistema deve manter apenas uma Planning Tool aberta por vez. Ao abrir a ferramenta de notas, o painel de outra ferramenta que estiver aberto deve deixar de ser exibido. |
| AC06 – | O sistema deve permitir que o teacher feche o painel do histórico de notas pelo controle de fechamento do painel. |
| AC07 – | O sistema deve permitir que o teacher feche o painel do histórico de notas ao selecionar novamente a ferramenta de notas que estiver aberta. |
| AC08 – | O sistema deve manter a ferramenta de notas visualmente destacada enquanto o painel do histórico de notas estiver aberto, seguindo o padrão visual das demais Planning Tools. |
| AC09 – | O painel do histórico de notas deve disponibilizar rolagem interna quando o conteúdo ultrapassar a área disponível para visualização. |
